# Logic-Building-Assignments
This repository contains foundational programming assignments focused on building logical thinking and problem-solving skills. Each assignment targets core concepts like conditionals, loops, patterns, recursion, and basic algorithms — implemented across three major languages.
Each assignment folder contains solutions written in : 
-   C
-   C++
-   Java

📚  Topics Covered
🔵 C

-  Variables, Data Types, Operators
-  Conditionals & Loops
-  Functions, Arrays, Pointers
-  Strings & File Handling

🟠 C++

-   OOP Concepts (Classes, Inheritance, Polymorphism)
-  Operator Overloading
-  Templates & STL Basics

🔴 Java

-  OOP (Classes, Objects, Inheritance)
-  Exception Handling
-  Collections Basics

🟣 Data Structures

-  Arrays & Matrices
-  Linked Lists (Singly, Doubly)
-  Stacks & Queues
-  Trees & Binary Search Trees
-  Sorting & Searching Algorithms
-  Recursion-based Problems
